# Afterhours redesign — 20 October 2026

## Reference and implementation

Inspected https://luma.com/kuala-lumpur and https://afterhours-kl.vercel.app/ using Computer Use, including the hero, scrolling event timeline, discovery sidebar, and event drawer. The existing Luma desktop/mobile measurements remain in `docs/research/luma/`.

The redesigned page follows Luma's system typography, 960px outer container, 52px desktop/32px mobile city title, 56px city icon, neutral surfaces, chronological dotted timeline, compact controls, square event art, and 550px detail drawer. Afterhours retains its branding and real nightlife inventory. A working search replaces the reference's subscription form; Events/Places navigation, venue Instagram links, and a map support nightlife discovery. These are intentional functional differences; full pixel identity is not claimed.

The header is fixed at 56px with a solid blurred background after 32px of scrolling. The old sticky header's IntersectionObserver watched the entire long main section and did not update when its top crossed the header; it kept transparent styling over the list. List controls and the desktop sidebar stay available while scrolling. Detail sheets use native modal dialogs, restoring focus and scroll state on close.

Public reference assets are bundled locally:

- `public/sites/luma/kl-desktop.jpg` from https://images.lumacdn.com/discovery/kl-desktop.jpg
- `public/sites/luma/kl-mobile.jpg` from https://images.lumacdn.com/discovery/kl-mobile.jpg
- `public/sites/luma/kl-icon.png` from https://images.lumacdn.com/discovery/kl-icon.png

The page credits Luma. Event artwork remains on its source CDN. Venue image provenance is in `src/data/places.json`. No generated or unrelated stock venue images are used.
